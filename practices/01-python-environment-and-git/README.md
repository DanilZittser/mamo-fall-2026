# О проекте

Учебный проект, на котором студенты знакомятся с виртуальным окружением Python, базовыми файлами проекта и основными командами git.

Папка — копия отдельного репозитория [mamo-practice-01-20261007](https://github.com/DanilZittser/mamo-practice-01-20261007), который создавался на занятии 07.10.2026. Команды ниже выполнялись в нём, поэтому `git clone` скачивает именно его.

Файлы проекта:

- `main.py` — простой скрипт, который выводит версию библиотеки `numpy`;
- `requirements.txt` — список зависимостей проекта с точными версиями;
- `.gitignore` — список файлов и папок, которые git не должен отслеживать;
- `notebooks/` — папка с Jupyter-ноутбуками;
- `README.md` — этот файл с описанием проекта.

# Как создавался этот репозиторий

Ниже перечислены команды в том порядке, в котором они выполнялись на занятии. Команды с пометкой «на занятии не показывали» добавлены для полноты: они понадобятся при самостоятельной работе.

## Клонирование репозитория

```bash
mkdir temp && cd $_  # создать папку и перейти в неё: && запускает вторую команду, только если первая прошла успешно, $_ — последний аргумент предыдущей команды
git --help  # краткая справка по командам git
git clone git@github.com:DanilZittser/mamo-practice-01-20261007.git  # скачать репозиторий с GitHub по SSH
ls  # показать содержимое текущей папки
cd mamo-practice-01-20261007/  # перейти в папку репозитория
```

## Виртуальное окружение

> Внимание! На занятии использовался **Python 3.8.10**.

```bash
which python3  # показать путь к интерпретатору: пока это системный Python 3.8.10
python3 --version  # показать версию Python
python3 -m venv venv  # создать виртуальное окружение в папке venv
source venv/bin/activate  # активировать окружение: в начале строки приглашения появится (venv)
which python3  # теперь путь ведёт внутрь venv
deactivate  # на занятии не показывали: выйти из виртуального окружения
```

## Зависимости и первый скрипт

```bash
pip install numpy  # установить пакет в активное окружение
pip freeze  # вывести список установленных пакетов с версиями
pip freeze > requirements.txt  # сохранить этот список в файл: > перенаправляет вывод команды в файл и перезаписывает его
cat requirements.txt  # вывести содержимое файла в консоль
nano main.py  # создать или отредактировать файл в консольном редакторе (Ctrl+O — сохранить, Ctrl+X — выйти)
python3 main.py  # запустить скрипт
pip install -r requirements.txt  # на занятии не показывали: установить все зависимости из файла, например на другом компьютере
```

## Первый коммит

```bash
nano README.md  # создать описание проекта
du  # показать размер папок: venv занимает много места, и хранить его в git не нужно
nano .gitignore  # перечислить то, что git должен игнорировать, — здесь это venv/
git status  # показать состояние репозитория: новые, изменённые и подготовленные к коммиту файлы; полезно запускать перед каждым add и commit
git add .  # добавить в индекс все изменения в текущей папке
git commit -m "initial commit"  # зафиксировать изменения из индекса с сообщением
git push  # отправить коммиты на GitHub
```

## Jupyter Notebook и второй коммит

```bash
pip install -U pip  # обновить сам pip до последней версии
pip install notebook  # установить Jupyter Notebook
pip freeze | wc -l  # посчитать установленные пакеты: | передаёт вывод одной команды на вход другой, wc -l считает строки
mkdir notebooks  # создать папку для ноутбуков
jupyter notebook  # запустить Jupyter в браузере; остановить — Ctrl+C в консоли
git add notebooks/  # добавить в индекс папку с ноутбуками
git restore --staged notebooks/.ipynb_checkpoints/01-dummy-notebook-checkpoint.ipynb  # убрать файл из индекса, сам файл остаётся на диске
nano .gitignore  # добавить правило для служебных папок .ipynb_checkpoints
git diff .gitignore  # показать, что изменилось в файле с момента последнего коммита
git add .gitignore  # добавить изменённый .gitignore в индекс
git commit -m "feat: jupyter notebook"  # зафиксировать изменения
git push  # отправить коммит на GitHub
git log  # показать историю коммитов (выход — q)
history  # показать историю команд, введённых в консоли
pip freeze > requirements.txt  # на занятии не показывали: обновить список зависимостей после установки новых пакетов
git pull  # на занятии не показывали: скачать изменения с GitHub, например сделанные на другом компьютере
```
